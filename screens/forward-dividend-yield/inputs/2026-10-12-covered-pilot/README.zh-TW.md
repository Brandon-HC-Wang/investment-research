## 3213

業務／盈餘基礎：強固系統需求及通路銷售驅動經常獲利。保留正常營運成本；以中性正常化敏感度剔除小額 H1 基金 FVTPL 與匯兌利益。[既有模型](../../../../companies/3213-crete/04_eps_model.md) FY2026 稀釋基準／下行為 **12.14828882595 / 9.3808437521**。假設邊際稅率 **25%**，扣除 `(2.962 + 3.275) × 75% / 59.316 = 0.07886152134` EPS，得到 **12.06942730461 / 9.30198223076**。下行模型已含 H2 匯損，不再重複剔除。本次未將未來 MilDef 處分收入計入經常盈餘／現金預估。

歷史一般 FCF 定義為營業現金流減現金 PPE（含預付款）與無形資產，尚未扣租賃本金。現金流 FY2023/FY2024/FY2025 為 **24.131 / 481.375 / 602.504**；同一現金流年度支付的一般現金股利為 **211.268 / 316.902 / 352.113**。三年合計覆蓋 **1.25869748706×**。付款年度總額刻意與盈餘年度 DPS 表分開。歷史比率是審查指標，不能證明 FY2026 現金轉換。

**條件式現金情境：**已揭露 H1 集團流動資金 **1,823.151**，扣租賃 **72.262**、已決議應付股利 **410.799**、當期應付稅 **196.264**，及分析者營運資金保留 **1,000.000**，剩 **143.826**。保留款是既有估值討論中的估計，不是公司揭露的現金限制。基準假設 H2 新增 FCF 為三年年度中位數的一半（**481.375 / 2**），下行為最低年度的一半（**24.131 / 2**）。即使 H1 CFO 為 **-373.577**，仍須驗證這些明列現金回收假說；它們不是盈餘機械年化，也不是已公布 H2 現金流。

基準現金上限 `(143.826 + 481.375 / 2) / 58.685 = 6.55215983641`，下行 `(143.826 + 24.131 / 2) / 58.685 = 2.65641134873`。基準 DPS 取正常化基本 EPS 的 **50%**、歷史一般 DPS 中位數 **6.00**、基準現金上限三者較低，為 **6.00**。下行取正常化基本 EPS 的 **40%** 與下行現金上限較低，向下取整為 **2.65**。以 **59.316 / 58.685** 股數將稀釋 EPS 換回基本盈餘能力；現金配發分母不使用稀釋股數。
