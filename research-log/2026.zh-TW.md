## 2026-08-04 — 研究系統合約成立

- **範圍：** 全儲存庫的方法論和未來的公司研究。
- **類型：** 方法改變。
- **發現：** 長期研究需要穩定的公司介面、明確的證據標籤、僅附加的假設歷史，以及從業務活動到估值前標準化每股收益的因果橋樑。
- **證據：** 儲存庫的初始原則和工作流程包含核心分析序列，但缺乏完整的文件契約、狀態模式、驗證和跨代理更新協議。
- **機制：**穩定的介面使公司證據可以跨代理尋址；僅附加修訂保留學習；因果 EPS 模型可防止收入或新聞摘要被誤用於收益分析。
- **信心：** 高。主要的不確定性在於這些約定在實際公司重複使用後將如何演變。
- **儲存庫影響：**新增了系統情境、代理合約、人工智慧工作流程、規範框架、評分和評估標準、產業和模型層、公司範本、元資料模式和驗證工具。
- **下一步驗證：** 將合約應用於第一家真正的公司，並記錄任何需要向後相容方法修訂的摩擦。

## 2026-09-09 — 建立高殖利率 FVTPL 篩選

- **範圍：** 上市與上櫃普通股。
- **類型：** 跨公司會計與盈餘品質篩選。
- **發現：** 2026-09-08 交易所顯示殖利率高於 5% 的 434 檔股票中，264 檔在 2026-06-30 有正數 FVTPL 金融資產；35 檔的 FVTPL 至少占總資產 10%。
- **證據：** TWSE 與 TPEx 殖利率 API、MOPS 2026Q2 Inline XBRL、TWSE 金融業資產負債表 OpenAPI，以及在 MOPS 批次存取限流時明確標示的 FinMind 補缺擷取。
- **機制：** 將價格型收益篩選與資產負債表投資曝險結合，可找出顯示殖利率與重大按市價評價盈餘波動可能並存的公司；工具組合與標準化股息覆蓋仍需逐家公司核對。
- **信心：** 中等。434 檔殖利率候選均已分類，但 264 檔 FVTPL 符合者中有 164 檔採次級結構化資料，仍待直接財報驗證。
- **儲存庫影響：** 新增 [`industries/FVTPLHighYieldScreen.md`](industries/FVTPLHighYieldScreen.md) 與完整 264 檔 CSV。
- **下一步驗證：** 優先直接核對 FVTPL 超過總資產 10% 的非金融公司財報，並將低波動基金與債券和股票、私募市場曝險分開。

## 2026-09-09 — 辨識策略研究架構缺口

- **範圍：** 單一公司研究以外的全儲存庫工作流程。
- **類型：** 架構評估；尚未建立新的正式目錄契約。
- **發現：** 儲存庫已有公司、總體 thesis、研究 watchlist、模型與投資組合風險層，但缺少可重複使用的策略假說、搜尋定義、點時結果、刷新排程與歷史驗證的第一級生命週期。
- **建議分層：** 未來的 `strategies/` 應保存可測試的經濟優勢假說及驗證狀態；未來的 `screens/` 應保存可重現的母體、篩選條件、來源、頻率與僅附加的結果快照。搜尋結果可以提名研究候選，但不得自動成為買進清單。
- **第一個候選：**「季末 FVTPL 盈餘 nowcast」— 以前一期揭露持倉作為起始庫存，在季末重估可觀察的上市證券與基金 NAV，將不可觀察部位另外建模，再把估計公允價值變動經稅率與歸屬關係橋接到 EPS，並在財報公布前與市場預期比較。
- **主要不確定性：** 前一季持倉可能在季中變動；未上市資產無法獨立估值；稅率、非控制權益、評價時點與市場提前反映都可能消除表面優勢。這個想法移出 `Testing` 前，必須進行點時歷史測試。
- **建議生命週期：** `Idea` → `Testing` → `Validated` → `Monitoring`，另有 `Rejected` 與 `Archived` 終止狀態。每個策略應包含 `last_run`、`next_refresh`、`refresh_trigger`、`stale_after`、信心、否證條件及定期搜尋結果連結。
- **儲存庫影響：** 已記錄缺口與建議邊界，未過早實作 schema 或自動化契約。
- **下一步驗證：** 在新增目錄、schema、模板、驗證或自動化之前，先審查並核准名稱、生命週期及策略假說與搜尋定義的分層方式。

## 2026-09-10 — 定義前瞻現金殖利率篩選

- **範圍：** 可能以 2026 年盈餘在 2027 年配發現金股利的上市與上櫃普通股。
- **類型：** 跨公司探索方法；不是推薦清單，也不是已驗證策略。
- **定義：** 前瞻現金殖利率為預估 2027 年每股現金股利除以篩選日股價。交易所顯示殖利率只作為探索輸入，因為它反映歷史配發，且可能包含非經常性或非盈餘支應的項目。
- **目前母體事實：** 2026-09-09 交易所 API 顯示殖利率至少 7% 的紀錄中，上市 65 檔、上櫃 76 檔，合計 141 檔。這個數量不是前瞻殖利率結果。
- **主要篩選：** 先估計標準化歸屬母公司 2026 年稀釋 EPS，再以保守可支持的配息率與母公司可分配現金能力兩者較低者估計現金 DPS。基本情境候選須同時符合：估計前瞻現金殖利率至少 7%、標準化 EPS 對所需 DPS 的覆蓋至少 1.25 倍，以及下行情境殖利率至少 5% 至 5.5%。
- **品質過濾：** 檢驗三至五年配息穩定性、三年自由現金流對現金股利的覆蓋、槓桿與利息保障、股數稀釋、流動性，以及 2027 年營收與 EPS 驅動因子的耐久性。金融業、營建／代銷業及景氣循環業須分開處理，因其資本、專案認列及標準化盈餘測試不同。
- **盈餘品質排除：** 資產處分、FVTPL 利得、匯兌利得、稅務迴轉、資本公積配發、減資及其他一次性項目須標記，不得自動資本化。顯示殖利率高於 7% 但標準化 EPS 或現金覆蓋弱者，應進入殖利率陷阱檢查，而不是可持續收益候選集。
- **證據：** 臺灣證券交易所，「上市個股日本益比、殖利率及股價淨值比」，資料日 2026-09-09，存取日 2026-09-10，[BWIBBU_ALL](https://openapi.twse.com.tw/v1/exchangeReport/BWIBBU_ALL)；證券櫃檯買賣中心，「上櫃股票個股本益比、殖利率、股價淨值比」，資料日 2026-09-09，存取日 2026-09-10，[tpex_mainboard_peratio_analysis](https://www.tpex.org.tw/openapi/v1/tpex_mainboard_peratio_analysis)；臺灣證券交易所 OpenAPI，存取日 2026-09-10，[公司財務、月營收及股利分派資料集目錄](https://openapi.twse.com.tw/)。
- **信心：** 資料可得性與顯示殖利率檔數為高；建議門檻為中等，仍須用點時測試確認基本與下行情境能多常預測後續董事會決議及股東會通過的現金股利。
- **儲存庫影響：** 已記錄可重現的前瞻殖利率定義與品質關卡，未建立仍待核准的 `screens/` 或 `strategies/` 契約。
- **下一步驗證：** 以僅附加的點時快照執行全市場篩選，揭露每一檔保留候選的 EPS 與配息假設，並與 2027 年董事會決議及股東會通過結果比較。

## 2026-09-10 — 完成搜尋策略架構草案

- **範圍：** 全 repository 可重複使用的 strategy definitions、可執行 screens、點時結果與刷新提醒。
- **類型：** 架構提案；尚未實作 schema、runner、網路自動化或 startup hook。
- **發現：** 長期邊界應區分可測試經濟假說 `strategy`、可重現搜尋 `screen`、不可變點時 `run`，以及可重建的刷新 `state`。這可避免把候選清單誤認為已驗證投資策略或公司 thesis。
- **刷新設計：** 到期狀態必須同時考慮執行新鮮度與輸入新鮮度。未來新 agent session 應執行本機 read-only check，回報已到期 screens 及 reason codes，不連線外部服務也不修改檔案。
- **儲存庫影響：** 新增雙語草案 [`../docs/proposals/SearchStrategyArchitecture.md`](../docs/proposals/SearchStrategyArchitecture.md)，涵蓋建議目錄、契約、刷新狀態、安全門及分階段實作。
- **下一步驗證：** 在新增 schemas、templates、validator rules、refresh tooling 或第一個正式 strategy 與 screen 前，先核准提案中的四項開放決策。
