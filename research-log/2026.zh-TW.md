## 2026-08-04 — 研究系統合約成立

- **範圍：** 全儲存庫的方法論和未來的公司研究。
- **類型：** 方法改變。
- **發現：** 長期研究需要穩定的公司介面、明確的證據標籤、僅附加的假設歷史，以及從業務活動到估值前標準化每股收益的因果橋樑。
- **證據：** 儲存庫的初始原則和工作流程包含核心分析序列，但缺乏完整的文件契約、狀態模式、驗證和跨代理更新協議。
- **機制：**穩定的介面使公司證據可以跨代理尋址；僅附加修訂保留學習；因果 EPS 模型可防止收入或新聞摘要被誤用於收益分析。
- **信心：** 高。主要的不確定性在於這些約定在實際公司重複使用後將如何演變。
- **儲存庫影響：**新增了系統情境、代理合約、人工智慧工作流程、規範框架、評分和評估標準、產業和模型層、公司範本、元資料模式和驗證工具。
- **下一步驗證：** 將合約應用於第一家真正的公司，並記錄任何需要向後相容方法修訂的摩擦。

- **類型：** 跨公司會計與盈餘品質篩選。
- **發現：** 2026-09-08 交易所顯示殖利率高於 5% 的 434 檔股票中，264 檔在 2026-06-30 有正數 FVTPL 金融資產；35 檔的 FVTPL 至少占總資產 10%。
- **證據：** TWSE 與 TPEx 殖利率 API、MOPS 2026Q2 Inline XBRL、TWSE 金融業資產負債表 OpenAPI，以及在 MOPS 批次存取限流時明確標示的 FinMind 補缺擷取。
- **機制：** 將價格型收益篩選與資產負債表投資曝險結合，可找出顯示殖利率與重大按市價評價盈餘波動可能並存的公司；工具組合與標準化股息覆蓋仍需逐家公司核對。
- **信心：** 中等。434 檔殖利率候選均已分類，但 264 檔 FVTPL 符合者中有 164 檔採次級結構化資料，仍待直接財報驗證。
- **儲存庫影響：** 新增 [`industries/FVTPLHighYieldScreen.md`](industries/FVTPLHighYieldScreen.md) 與完整 264 檔 CSV。
- **下一步驗證：** 優先直接核對 FVTPL 超過總資產 10% 的非金融公司財報，並將低波動基金與債券和股票、私募市場曝險分開。

## 2026-09-09 — 辨識策略研究架構缺口

- **範圍：** 單一公司研究以外的全儲存庫工作流程。
- **類型：** 架構評估；尚未建立新的正式目錄契約。
- **發現：** 儲存庫已有公司、總體 thesis、研究 watchlist、模型與投資組合風險層，但缺少可重複使用的策略假說、搜尋定義、點時結果、刷新排程與歷史驗證的第一級生命週期。
- **建議分層：** 未來的 `strategies/` 應保存可測試的經濟優勢假說及驗證狀態；未來的 `screens/` 應保存可重現的母體、篩選條件、來源、頻率與僅附加的結果快照。搜尋結果可以提名研究候選，但不得自動成為買進清單。
- **第一個候選：**「季末 FVTPL 盈餘 nowcast」— 以前一期揭露持倉作為起始庫存，在季末重估可觀察的上市證券與基金 NAV，將不可觀察部位另外建模，再把估計公允價值變動經稅率與歸屬關係橋接到 EPS，並在財報公布前與市場預期比較。
- **主要不確定性：** 前一季持倉可能在季中變動；未上市資產無法獨立估值；稅率、非控制權益、評價時點與市場提前反映都可能消除表面優勢。這個想法移出 `Testing` 前，必須進行點時歷史測試。
- **建議生命週期：** `Idea` → `Testing` → `Validated` → `Monitoring`，另有 `Rejected` 與 `Archived` 終止狀態。每個策略應包含 `last_run`、`next_refresh`、`refresh_trigger`、`stale_after`、信心、否證條件及定期搜尋結果連結。
- **儲存庫影響：** 已記錄缺口與建議邊界，未過早實作 schema 或自動化契約。
- **下一步驗證：** 在新增目錄、schema、模板、驗證或自動化之前，先審查並核准名稱、生命週期及策略假說與搜尋定義的分層方式。

## 2026-09-10 — 定義前瞻現金殖利率篩選

- **範圍：** 可能以 2026 年盈餘在 2027 年配發現金股利的上市與上櫃普通股。
- **類型：** 跨公司探索方法；不是推薦清單，也不是已驗證策略。
- **定義：** 前瞻現金殖利率為預估 2027 年每股現金股利除以篩選日股價。交易所顯示殖利率只作為探索輸入，因為它反映歷史配發，且可能包含非經常性或非盈餘支應的項目。
- **目前母體事實：** 2026-09-09 交易所 API 顯示殖利率至少 7% 的紀錄中，上市 65 檔、上櫃 76 檔，合計 141 檔。這個數量不是前瞻殖利率結果。
- **主要篩選：** 先估計標準化歸屬母公司 2026 年稀釋 EPS，再以保守可支持的配息率與母公司可分配現金能力兩者較低者估計現金 DPS。基本情境候選須同時符合：估計前瞻現金殖利率至少 7%、標準化 EPS 對所需 DPS 的覆蓋至少 1.25 倍，以及下行情境殖利率至少 5% 至 5.5%。
- **品質過濾：** 檢驗三至五年配息穩定性、三年自由現金流對現金股利的覆蓋、槓桿與利息保障、股數稀釋、流動性，以及 2027 年營收與 EPS 驅動因子的耐久性。金融業、營建／代銷業及景氣循環業須分開處理，因其資本、專案認列及標準化盈餘測試不同。
- **盈餘品質排除：** 資產處分、FVTPL 利得、匯兌利得、稅務迴轉、資本公積配發、減資及其他一次性項目須標記，不得自動資本化。顯示殖利率高於 7% 但標準化 EPS 或現金覆蓋弱者，應進入殖利率陷阱檢查，而不是可持續收益候選集。
- **證據：** 臺灣證券交易所，「上市個股日本益比、殖利率及股價淨值比」，資料日 2026-09-09，存取日 2026-09-10，[BWIBBU_ALL](https://openapi.twse.com.tw/v1/exchangeReport/BWIBBU_ALL)；證券櫃檯買賣中心，「上櫃股票個股本益比、殖利率、股價淨值比」，資料日 2026-09-09，存取日 2026-09-10，[tpex_mainboard_peratio_analysis](https://www.tpex.org.tw/openapi/v1/tpex_mainboard_peratio_analysis)；臺灣證券交易所 OpenAPI，存取日 2026-09-10，[公司財務、月營收及股利分派資料集目錄](https://openapi.twse.com.tw/)。
- **信心：** 資料可得性與顯示殖利率檔數為高；建議門檻為中等，仍須用點時測試確認基本與下行情境能多常預測後續董事會決議及股東會通過的現金股利。
- **儲存庫影響：** 已記錄可重現的前瞻殖利率定義與品質關卡，未建立仍待核准的 `screens/` 或 `strategies/` 契約。
- **下一步驗證：** 以僅附加的點時快照執行全市場篩選，揭露每一檔保留候選的 EPS 與配息假設，並與 2027 年董事會決議及股東會通過結果比較。

- **控制：** Executor 分離擷取與評估、支援不修改資料的 dry run、拒絕重複與不安全 run ID、原子式建立 manifest/results/雙語摘要、記錄來源與門檻 provenance，且只有完整成功後才推進 `state.yaml`。Repository validation 會檢查 artifact 路徑限制、結果結構與筆數，以及 results SHA-256。
- **預先聲明的測試指標：** 三個年度 cohorts 且至少 100 個 company-year observations；forecast-interval coverage 至少 70%；DPS 絕對誤差中位數不高於 15%；候選 precision 至少 60%；且 precision 至少比顯示殖利率 baseline 高 10 個百分點。這些門檻是待驗證假說，不代表 strategy 已獲驗證。
- **驗證：** 二十二個單元測試通過，涵蓋 dry-run 不可變性、partial-state 行為、重複公司列、重複與不安全 run IDs、輸入日期一致性、concurrent-run locking、產生 run 的 validation 及竄改偵測。交付前仍需完成 repository validation 與 diff checks。Synthetic fixture 在 dry-run 模式產生兩個候選，但它不是研究證據，也未被持久化。
- **Repository 影響：** 新增 `scripts/run_screen.py`、明確 synthetic fixture、run-lifecycle tests、擴充 screen 輸入／輸出契約、強化 run validation，並同步雙語操作文件。未建立 `runs/` 目錄或正式結果；刷新 state 對 `never_run` 與 `definition_changed` 仍維持 `due`。
- **下一步驗證：** 實作分離測試的官方來源輸入 adapters，記錄每個數值假設的 normalization provenance，審查一份有日期的全市場輸入，之後才授權第一次 append-only 點時 run。

## 2026-09-14 — 完成官方 market-discovery adapter

- **範圍：** `forward-dividend-yield` 研究流程使用的 TWSE 與 TPEx 官方股價及顯示殖利率蒐集。
- **類型：** Source-adapter 與 provenance 實作；不是盈餘模型、正式 source snapshot、screen run 或投資建議。
- **發現：** 將官方殖利率資料集依市場與 ticker，和同資料日的收盤價資料集連結後，可形成可重現、保留所有紀錄的 market-discovery table。顯示殖利率門檻只保留為審查優先標籤，不會從表中刪除證券。
- **來源契約：** 2026-09-14 存取的 TWSE `BWIBBU_ALL`、`STOCK_DAY_ALL`，以及 TPEx `tpex_mainboard_peratio_analysis`、`tpex_mainboard_daily_close_quotes`。官方回應採民國日期且欄位名稱不同，因此 adapter 會標準化日期、身分、股價、顯示殖利率、來源有提供時的 DPS、本益比與股價淨值比，同時保留來源 URLs 與 raw JSON。
- **診斷觀察：** 對 endpoints 2026-09-11 回應進行未持久化 contract replay，包含 1,080 筆 TWSE 與 885 筆 TPEx 殖利率紀錄。1,965 筆中有 1,939 筆連結到有效股價，26 筆不完整；顯示殖利率門檻為 5% 時，有 441 筆標示為優先審查。這個 `partial` dry run 只是工具診斷，不是保留的研究證據或前瞻殖利率候選數。
- **控制與限制：** Live collection 必須明確執行並通過 TLS verification、核對四個來源日期皆等於 `--as-of`、保存 raw 與 normalized SHA-256 checksums、拒絕覆寫，且不能填入標準化 EPS 或前瞻 DPS。目前 command-line 環境不信任 TPEx 的本機 certificate chain；檢查使用暫時且未持久化的診斷下載，而 production collector 不允許 insecure TLS。保存第一份正式 snapshot 前，必須提供可信任 CA bundle。
- **Repository 影響：** 新增 `scripts/collect_market_discovery.py`、synthetic source-contract fixtures 與 tests、`market-discovery-snapshot.schema.json`、append-only `source-snapshots/` 指引、更強的 repository validation，並同步雙語架構文件。Screen definition version 已升至 3；因尚無正式 run，仍維持 due。
- **驗證：** 全 repository 三十二個測試通過。Source collection 與 screen execution 的 fixture dry runs 均不修改資料；repository validation 與 diff checks 通過；`source-snapshots/` 目前只有指引，`runs/` 仍不存在。
- **下一步驗證：** 解決嚴格 TPEx certificate validation、執行並驗證第一份保留的官方市場 snapshot，之後再設計分離的財報與 analyst-assumption enrichment contract；在此之前不得建立正式 screen run。

**主要來源：** 臺灣證券交易所，[BWIBBU_ALL](https://openapi.twse.com.tw/v1/exchangeReport/BWIBBU_ALL) 與 [STOCK_DAY_ALL](https://openapi.twse.com.tw/v1/exchangeReport/STOCK_DAY_ALL)；證券櫃檯買賣中心，[tpex_mainboard_peratio_analysis](https://www.tpex.org.tw/openapi/v1/tpex_mainboard_peratio_analysis) 與 [tpex_mainboard_daily_close_quotes](https://www.tpex.org.tw/openapi/v1/tpex_mainboard_daily_close_quotes)，存取日 2026-09-14。

- **揭露界線：** 這些是預估分配類別，並非最終受益人通知書，也不是基金全部收入的對帳。截至 2026-09-24，2026-10-15 的款項仍待發放。分配中的股利占比為零，不代表基金沒有收到股利。這些揭露不能確認所配資本利得於何時賺得，也不能證明未來各期維持相同組成。
- **比率定義：** 組合現金股利殖利率必須對齊日期並以市值權重加權，不能簡單平均各股殖利率。基金實際股利收入還取決於取得股利權利時的持股、換股與受益單位申贖。ETF 過去配息率為最近四季配息合計除以指定價格；單季乘年化倍數是不同計算。群益最新紀錄為 TWD 1.10、當季配息率 3.37%，分母是除息前一營業日淨值。將已四捨五入的比率乘以 4，得到示意年化 13.48%，並非預測或已實現年報酬。
- **機制：** 依基金適用契約，現金分配可包含股票股利、其他合格收入、已實現利得、累積可分配餘額及收益平準金。已實現利得是投資獲利，但配出該利得不代表整體組合在當期賺得同等金額，因為可能同時有未實現損失。收益平準金將初級市場申贖款項中的部分金額歸屬於累積收益，避免單位數變動稀釋既有配息權益；它不創造投資獲利，不能證明 3% 的獲利能力變成 11%。
- **淨值與定價：** 每單位淨值等於投資組合資產（含現金及應收款）減負債，再除以流通單位數。交易價格由市場撮合形成；申購買回套利通常使其在成本與市場限制範圍內貼近淨值。因此，用可調整的配息除以期望殖利率，不能作為 ETF 獨立估值基準。其他條件不變時，ETF 配息使淨值減少同額金額。成分股除息的價格調整，在基金內有應收股利對應，不能把收到股利再計為額外意外獲利。
- **示例，非 00919 實績：** 假設沒有申贖，期初 TWD 100、淨收入 TWD 3、淨資本報酬為零、分配 TWD 11，且該分配符合規定並有足夠可分配餘額。期末資產為 TWD 92，加上分配現金為 TWD 103，總報酬 3%。若另有 TWD 8 淨資本利得，期末資產為 TWD 100，總報酬為 11%。配息改變財富在基金與現金之間的配置，本身不增加財富。
- **風險與監測：** 股市疲弱可能壓低淨值並減少可分配利得的補充；維持配息可能消耗歷年累積餘額，或必須調降配息。成分股盈餘與股利下降，也會削弱經常性收入。應追蹤每單位淨股利收入、已實現與未實現損益、累積可分配餘額、費用、配息，以及相對適當含息基準的時間加權總報酬。淨值下降本身不能證明配息不當，必須分辨除息調整與市場報酬；持有期間總報酬為正，也不必然需要完全填息。

## 2026-09-24 — ETF 資金流、持股集中與串通指控的證據門檻

- **範圍／類型：** 延續 00919 配息分析；屬因果解讀與尚未驗證的市場資金流假說，並非違規認定或本波台股上漲的量化歸因。
- **結論：** 台股 ETF 淨申購與建倉可以產生成分股需求。相似投資規則可在沒有協調的情況下使需求集中。持股重疊與資本利得配息，都不能證明串通。新基金檔數、交易所成交額與 ETF 總規模，不等於新增台股買盤。
- **機制：** 次級市場購買 ETF 是投資人之間轉移既有單位；初級市場申購買回才改變流通單位數。現金申購可帶來底層股票買盤；實物申購則轉入可能已持有或已避險的證券。若申購資金來自賣掉既有台股或其他台股 ETF，表面流入可能部分抵銷。海外與債券 ETF 必須分開。規模成長也包含資產升值；股價上漲可能吸引申購，形成反向因果。
- **假說 ETF-FLOW-H01：** 當所需買盤相對可交易供給與市場深度較大，持股重疊基金的大量淨申購，可能放大短期價格壓力。狀態 Open；對機制的信心中等，對本波行情尚未量測的貢獻信心低。可能的循環為申購 → 買股 → 股價上升 → 實現利得配息／績效曝光 → 更多申購。支持證據是已公開的申購買回機制；反向因素包括贖回、既有股票部位轉換、實物移轉及對盈餘改善的共同反應。確認訊號應包括資金流先於異常報酬、買盤壓力越大效果越強，並控制盈餘消息、全球市場與其他投資人資金流。若實測台股需求很小、與推升指數的股票重疊低，或控制其他因素後關係消失，應否定其為主因的主張。擬檢驗募集／換股附近的每日事件窗口及後續 1–3 個月；尚未完成研究。
- **經濟受益者：** 基金交易利得留在基金資產中，歸受益人享有；經理費是另外的契約報酬。擴大規模可增加費用收入並帶來商業誘因，但不能據此認定經理人私取資本利得。經理人通常任職投信；銀行的銷售／保管角色或同屬金控，不等於它就是投資決策者。一般股票價差、ETF 市價／淨值套利與不當交易，必須區分。
- **違規證據界線：** 證期局 2023-09-12 對富邦與保德信投信的裁罰，記載具體合規缺失；富邦部分描述特定前經理人使用職務所得資訊，透過特定人帳戶交易，以及未申報個人交易。這表示實際利益衝突可能發生；並非指向 00919、ETF 全產業串通或本波大盤上漲原因的證據。協調交易指控需要關聯帳戶／委託、通訊、實質受益人或金流，以及調查認定。同向交易也可能來自相似投資規則。本次不是完整執法案件普查。
- **風險／下一步查證：** 即使没有違規，資金反轉也可能壓低集中持股並減少未來可分配利得。歸因行情前，先定義指數及起訖日期；將台股 ETF 每日單位數與淨值變化對帳至申贖揭露，估算成分股需求相對流動性，並拆解個股對指數報酬的貢獻及盈餘、估值變化。公開資料可能辨識擁擠交易，但本身不足以證實私下協調。
