# 研究日誌

<!-- 衍生繁體中文閱讀版；英文原檔 `README.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

研究日誌是對多個公司產生重大影響、改變可重複使用的假設或解釋重大儲存庫層級研究決策的結果的僅附加記錄。僅公司歷史屬於公司時間線。

## 文件組織

- [`companies/`](companies/README.md) 每家公司包含一個僅附加日誌，其名稱與公司目錄完全相同。
- [`industries/`](industries/README.md) 每個產業或持久週期包含一個僅附加日誌。
- 現有年度文件（例如 [`2026.md`](2026.md)）保留為向後相容的儲存庫範圍日誌，不會移動或刪除。

依時間順序附加條目，格式為 [`../templates/ResearchLogEntry.md`](../templates/ResearchLogEntry.md)。

## 納入標準

條目應記錄重大發現、其證據、因果機制、置信度、受影響的規範記錄以及下一步驗證。常規新聞、未經檢驗的評論和重複的公司觀察不屬於這裡。

切勿刪除或默默地重寫條目。添加稍後的更正、解決、拒絕或取代假設，並將其連結到較早的條目。
