# Templates

Templates enforce durable record shapes and evidence discipline.

| Template | Use |
|---|---|
| [`company/`](company/) | Complete fixed company record with research state, assumptions, sources, and history |
| [`SourceRecord.md`](SourceRecord.md) | Consistent source capture and analytical extraction |
| [`QuarterlyReview.md`](QuarterlyReview.md) | Periodic result review against prior assumptions |
| [`ResearchLogEntry.md`](ResearchLogEntry.md) | Append-only material finding or hypothesis event |
| [`reports/investment-research-report.html`](reports/investment-research-report.html) | Self-contained, responsive, printable HTML skeleton for a derived company research report |

Templates contain instructions and field definitions, not fictional evidence. Remove instructional text when instantiating an active record, while preserving required headings and tables.

The HTML report template is a derived presentation starting point. Populate it from canonical research records and follow [`../docs/ui-specs/research-report.md`](../docs/ui-specs/research-report.md); never use the template as evidence.
