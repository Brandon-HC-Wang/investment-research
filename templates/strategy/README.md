# Strategy Template

Use this directory only after the strategy ID, testable claim, causal mechanism, validation threshold, and linked screens are approved. Copy it to `strategies/<strategy-id>/`, replace every instructional value with real content, and register the definition in `strategies/registry.yaml`.

The final reasoning document must cover current validation state, supporting and contradicting evidence, confirmation and rejection signals, expected time window, limitations, linked screens, and append-only status history. A strategy is not a recommendation.
