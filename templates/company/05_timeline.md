# Timeline

This is an append-only history of events that changed the business, model, evidence base, or thesis. Routine news without analytical impact does not belong here.

## Event format

Each entry includes:

- **Date:** ISO date of the event or conclusion.
- **Event:** concise factual description with source.
- **Analytical impact:** changed operating driver, EPS assumption, risk, or thesis condition.
- **Records updated:** relative links to affected company files.
- **Confidence:** low, medium, or high, with the main uncertainty.

Keep entries in chronological order. Corrections and reversals receive new dated entries; never alter an old entry to match the current view.
