# Research Models

This directory defines reusable analytical conventions. Models express causal relationships and assumptions; they do not replace company-specific spreadsheets or evidence.

- [`EPSModel.md`](EPSModel.md) defines the standard earnings bridge and scenario architecture.
- [`ScenarioAnalysis.md`](ScenarioAnalysis.md) defines uncertainty, sensitivities, and probability discipline.

Any external spreadsheet should be reproducible from assumptions documented in the company’s `04_eps_model.md`, including version date, units, formulas, and source references.
