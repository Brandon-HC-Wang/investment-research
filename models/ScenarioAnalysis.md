# Scenario Analysis Standard

## Purpose

Scenarios describe distinct causal paths through uncertainty. They are not arbitrary percentage adjustments to a base forecast.

## Build scenarios

1. Identify the one or two uncertainties with the largest EPS effect.
2. Define observable states for each uncertainty.
3. Translate each state through revenue, margin, EPS, cash flow, and balance sheet.
4. State the evidence that would move the company from one scenario toward another.
5. Keep valuation inputs separate from operating outcomes.

## Required cases

- **Downside:** a credible adverse path, including second-order effects and financing constraints where relevant.
- **Base:** the path best supported by current evidence, not simply management guidance.
- **Upside:** a plausible favorable path requiring explicit evidence and execution.

## Probability discipline

Probabilities are optional. If used, they must sum to 100%, include a dated rationale, and not conceal a missing scenario. Do not treat the probability-weighted result as more precise than the underlying evidence.

## Sensitivity

Use sensitivities for continuous variables such as gross margin, ASP, utilization, FX, or discount rate. Use scenarios for discrete mechanisms such as qualification success, project delay, acquisition, customer loss, or regulatory change.

## Review triggers

Attach leading indicators and dates to each scenario. When a trigger occurs, update the assumption register, preserve the prior case, and document the thesis effect in the timeline.
