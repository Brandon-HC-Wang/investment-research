# 研究策略

Strategy 說明一個訊號為何可能找得到研究機會，以及如何驗證或否證該主張。它不保存市場搜尋結果，也不構成投資建議。

Machine-readable definitions 登錄於 [`registry.yaml`](registry.yaml)。每個 strategy 目錄以 `strategy.yaml` 搭配英文與繁體中文推理文件。狀態歷史僅能附加。

## 啟用中的定義

- [`forward-dividend-income/`](forward-dividend-income/README.md) — 測試標準化盈餘與可分配現金能否找出可持續的前瞻現金殖利率。
