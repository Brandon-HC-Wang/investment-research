# 投資組合研究層

<!-- 衍生繁體中文閱讀版；英文原檔 `README.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

這一層將公司和宏觀研究與投資組合層面的思維連結起來。它不會改變公司的宗旨，也不提供交易指示。

## 職責

- [`watchlist.md`](watchlist.md) 將研究主題對應到與投資組合相關的監控角色。
- [`allocation.md`](allocation.md) 定義分配決策的證據與約束閘。
- [`risk_management.md`](risk_management.md) 定義風險敞口、相關性、流動性和論文風險控制。

現有的 [`../watchlist/`](../watchlist/README.md) 仍然是規範的研究優先隊列。組合文件可以引用它，但不得複製其工作流程狀態。

## 工作原理

投資組合結論從公司層面的可持續收益開始，然後考慮估值、情境不對稱性、相關性、流動性和整體風險敞口。強而有力的公司論點是必要的，但不足以進行分配。
