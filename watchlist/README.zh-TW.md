# 研究觀察清單

<!-- 衍生繁體中文閱讀版；英文原檔 `README.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

觀察清單用來排列研究行動與監控觸發條件的優先順序。它不是投資組合、推薦名單或預期報酬排名。

canonical、機器可讀的佇列為[`watchlist.yaml`](watchlist.yaml)。建立公司目錄後才能加入公司。每一筆資料都必須連結至該目錄，並包含明確的研究理由、下一步行動、觸發條件、優先序及複查日期。

## 優先序政策

- `1`：新證據可能重大改變論點或解決主要不確定性。
- `2`：目前研究週期內應完成的重要工作。
- `3`：一般監控或模型維護。
- `4`：等待明確觸發條件。
- `5`：刻意延後或封存。

優先序代表研究急迫性，不代表信念或吸引力。移除項目前，必須先在公司時間軸或研究日誌附加說明原因。
