# Reusable Investment Knowledge

This layer stores concepts that apply across industries and companies. A concept belongs here when multiple company records can reference the same definition, causal model, evidence hierarchy, or analytical failure mode.

Knowledge files never contain a company thesis or company-specific forecast. Examples, if used, illustrate mechanics and must link back to canonical company research.
