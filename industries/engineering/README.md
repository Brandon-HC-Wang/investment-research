# Engineering Industry Knowledge Package

## Scope

This package covers engineering, procurement and construction, industrial services, and project-based technical contractors. Business quality depends less on headline backlog than on contract terms, execution, margin, customer credit, and cash conversion.

The legacy overview remains at [`../Engineering.md`](../Engineering.md). This package is canonical for new reusable research.

## Economic model

Orders enter backlog and become revenue through mobilization, physical progress, contractual milestones, or customer acceptance. EPS depends on bid margin, project mix, fixed-price exposure, procurement, labor, change orders, delays, provisions, financing, and tax.

## Package map

- [`metrics.md`](metrics.md) defines backlog, execution, margin, and cash metrics.
- [`valuation.md`](valuation.md) explains normalization for project businesses.
- [`open_questions.md`](open_questions.md) tracks common evidence gaps.

## Update rule

Keep customer and project data in company folders. Promote a finding here when it changes the reusable interpretation of contract quality, recognition, or execution risk.
