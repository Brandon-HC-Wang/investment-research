# Industry Knowledge

Industry records store reusable economics, value-chain structure, KPIs, cycle mechanics, accounting issues, and common failure modes. They prevent company folders from becoming isolated analyses and should be updated when company research reveals a sector-wide insight.

## Canonical knowledge packages

- [`construction/`](construction/README.md)
- [`property-agency/`](property-agency/README.md)
- [`semiconductor/`](semiconductor/README.md)
- [`engineering/`](engineering/README.md)
- [`ai-hardware/`](ai-hardware/README.md)

Each package separates industry context, operating metrics, valuation conventions, and durable open questions. This structure lets agents load only the layer required for a task.

## Backward compatibility

The original single-file guides—`Construction.md`, `PropertyAgency.md`, `Semiconductor.md`, `Engineering.md`, and `AIHardware.md`—remain in place so existing links and prior agent workflows continue to work. New reusable research should be written to the package files. Legacy guides may link forward to packages but must not be deleted during the compatibility period.

An industry guide is a starting framework, not a substitute for company-specific evidence. Link company conclusions to the relevant guide when the insight generalizes.
