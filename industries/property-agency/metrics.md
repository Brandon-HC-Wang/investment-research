# Property Agency Metrics

## Brokerage and agency metrics

| Metric | Revenue or EPS connection |
|---|---|
| Addressable transaction value | Establishes the market activity pool |
| Represented project sales value | Measures the inventory available to a project-sales agent |
| Market share | Converts market activity into company transaction value |
| Effective take rate | Converts transaction value into revenue |
| Sell-through and cancellation | Tests demand quality and execution |
| Active branches, sites, or agents | Defines capacity and part of the fixed-cost base |
| Revenue per branch, site, or agent | Measures productivity and operating leverage |
| Repeat-developer mandates | Tests relationship strength and potential advantage |
| Personnel and advertising cost | Determines margin sensitivity to transaction volume |

## Development and investment metrics

Track every owned or invested project by attributable ownership, invested capital, presales, expected completion, recognition method, gross margin, distributions, guarantees, and remaining funding. Never mix represented gross sales with attributable development economics.

## Earnings-quality checks

Separate recurring fees from development recognition, investment gains, fair-value changes, and disposals. Reconcile reported profit with cash collection and changes in inventory, contract assets, deposits, and project debt.

## Warning indicators

Monitor falling transaction volume, take-rate pressure, declining productivity, rising fixed selling costs, developer concentration, project delays, increased guarantees, and a lack of replacement mandates or owned completions.
