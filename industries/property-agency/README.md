# Property Agency Industry Knowledge Package

## Scope

This package covers real-estate brokerage, project sales agencies, and businesses that combine agency work with development or investment projects. These activities must be separated because recurrence, capital intensity, cash conversion, and valuation differ.

The legacy overview remains at [`../PropertyAgency.md`](../PropertyAgency.md). New reusable research belongs in this package.

## Economic model

Brokerage revenue is generally driven by transaction value, market share, and take rate. Project-sales agencies add represented project supply, sell-through, and contract terms. Development and investment projects create discrete, capital-intensive earnings that should be modeled by project and year.

## Package map

- [`metrics.md`](metrics.md) defines activity, productivity, and project metrics.
- [`valuation.md`](valuation.md) separates recurring agency value from project value.

## Update rule

Store company mandates, projects, clients, and forecasts in company records. Promote evidence here only when it clarifies a reusable agency or property-cycle mechanism.
