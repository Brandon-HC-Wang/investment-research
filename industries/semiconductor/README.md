# Semiconductor Industry Knowledge Package

## Scope

This package covers semiconductor design, manufacturing, packaging and testing, equipment, materials, distribution, and memory. Company research must identify the value-chain position because inventory ownership, capacity economics, pricing, and cycle exposure differ.

The legacy overview remains at [`../Semiconductor.md`](../Semiconductor.md). This package is canonical for new reusable research.

## Economic model

Revenue combines end demand, semiconductor content, market share, units, ASP, mix, and FX. EPS adds utilization, yield, depreciation, inventory provisions, R&D intensity, tax, investment income, and diluted shares. Sell-in can diverge from sell-through during inventory corrections.

## Package map

- [`metrics.md`](metrics.md) defines demand, inventory, capacity, pricing, and margin measures.
- [`valuation.md`](valuation.md) addresses cycle normalization and value-chain differences.
- [`open_questions.md`](open_questions.md) preserves unresolved cycle and technology questions.

## Update rule

Company-specific nodes, customers, products, and forecasts stay in company records. Add a finding here when it improves the shared interpretation of cycle, capacity, architecture, or accounting evidence.
