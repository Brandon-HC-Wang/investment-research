# 證券經紀產業知識包

建立於 2026-10-12。券商收入包括交易手續費、融資利差、承銷／服務費及交易／造市報酬。資產管理可能採合併或關聯企業認列；持股與會計範圍決定獲利列在哪裡。

營收穩定性取決於成交值、費率、放款餘額、利差、平均管理資產（AUM）、淨流量與市場淨曝險。經常收費機制仍可能有循環。股災初期可能增加交易，之後交易與融資萎縮，應分階段評估。

閱讀[指標](metrics.md)、[估值](valuation.md)及[問題](open_questions.md)。公司證據及估計存於[群益證](../../companies/6005-capital-securities/01_business.md)；本包定義可重用分析規則，不是產業預測。
