# AI Hardware Industry Knowledge Package

## Scope

This package covers AI servers, accelerators, networking, memory, power, thermal systems, storage, racks, edge devices, and AI PCs. “AI exposure” must be converted into identifiable content, units, customers, timing, and incremental profit.

The legacy overview remains at [`../AIHardware.md`](../AIHardware.md). This package is canonical for new reusable research.

## Economic model

Revenue can be modeled as deployed systems × company content per system × share × ASP × mix. EPS additionally depends on pass-through components, bargaining power, ramp costs, warranty, working capital, customer concentration, and operating leverage.

## Package map

- [`metrics.md`](metrics.md) defines platform, content, qualification, supply, and margin evidence.
- [`valuation.md`](valuation.md) distinguishes durable content growth from temporary ramps.
- [`open_questions.md`](open_questions.md) tracks shared uncertainties.

## Update rule

Store company customers, qualifications, and forecasts in company records. Add reusable platform or architecture mechanics here and link to the relevant concept in `knowledge/` when one exists.
