# 行業知識

<!-- 衍生繁體中文閱讀版；英文原檔 `README.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

產業記錄儲存可重複使用的經濟學、價值鏈結構、KPI、循環機制、會計問題和常見故障模式。它們可以防止公司資料夾成為孤立的分析，並且應該在公司研究揭示全行業洞察力時進行更新。

## 規範知識包

- [`construction/`](construction/README.md)
- [`property-agency/`](property-agency/README.md)
- [`semiconductor/`](semiconductor/README.md)
- [`engineering/`](engineering/README.md)
- [`ai-hardware/`](ai-hardware/README.md)

每個包都將行業背景、營運指標、估值慣例和持久的開放性問題分開。這種結構允許代理僅載入任務所需的層。

## 向後相容性

原始單文件指南（`Construction.md`、`PropertyAgency.md`、`Semiconductor.md`、`Engineering.md` 和 `AIHardware.md`）保留在原處，以便現有連結和先前的代理工作流程繼續工作。新的可重複使用研究應寫入包文件中。舊版指南可能會連結到軟體包，但在相容期內不得刪除。

產業指南是一個起始框架，不能取代公司特定的證據。當見解概括時，將公司結論與相關指南連結起來。
