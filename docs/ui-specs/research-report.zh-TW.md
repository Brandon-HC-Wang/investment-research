# 投資研究報告 UI 規格

<!-- 衍生繁體中文閱讀版；英文原檔 `research-report.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

## 目的

本規格定義公司長篇研究可重複使用的 HTML 呈現系統。介面應讓證據、不確定性、因果關係、情境差異及驗證工作更容易理解，但不能把研究包裝成宣傳式 Dashboard。

報告是衍生閱讀產物。公司、產業、模型與研究日誌的 canonical 記錄仍是唯一資料來源。

## 產品輪廓

| 屬性 | 標準 |
|---|---|
| 產品類型 | 結合資料 Dashboard 元素的長篇投資研究報告 |
| 主要讀者 | 閱讀 AI 維護研究記錄的人類分析者 |
| 預設語言 | 呈現給使用者的繁體中文閱讀版 |
| 實作 | 單一 HTML，內嵌 CSS 及最少量 JavaScript |
| 網路依賴 | 版面、字體、圖示及互動均不需要網路 |
| 主要用途 | 桌機閱讀、手機複查、列印及輸出 PDF |
| 研究立場 | 中性、證據優先、情境導向且不具宣傳性 |

## 資訊架構

視覺結構遵循 Repository 的推理鏈：

1. 報告身分、資料截止日、研究階段與信心。
2. 核心結論及結論邊界。
3. 商業模式與客戶價值。
4. 競爭優勢及證據品質。
5. 財務輪廓及獲利品質。
6. 營收與 EPS 驅動因素。
7. 案量、pipeline、接替動能及未來能見度。
8. 營運情境與 EPS 橋接。
9. 認列延後與永久經濟損失的區別。
10. 一至兩項主要風險、預警訊號及未決問題。
11. 投資論點、確認、否證及估值狀態。
12. 資料來源、方法與報告限制。

估值不得排在商業、獲利品質、能見度與風險之前。報告不得包含買進、賣出或持有指示。

## 視覺原則

### 資訊密集，但不擁擠

用 Dashboard grid 比較資料，用文件式流程呈現推理。KPI 卡只能摘要已解釋的指標，不能取代因果分析。表格只用於精確對應、多期比較、情境輸入或永久識別碼。

### 證據必須可見

除了顏色，也要使用文字標籤：

| 證據類別 | 標籤 | 視覺角色 |
|---|---|---|
| 已申報事實 | `Fact` | 藍色 |
| 分析估計 | `Estimate` | 琥珀色 |
| 可驗證假設 | `Hypothesis` | 紫色或中性外框 |
| 分析意見 | `Opinion` | 中性色 |
| 未決問題 | `Open` | 琥珀色 |
| 重大下行機制 | `Risk` | 紅色 |

管理階層目標及第三方財測必須保留歸屬，不得因數字精確就標記為 `Fact`。

### 信心不是多空情緒

研究信心代表證據品質。應與資料截止日並列，使用 `Low`、`Medium` 或 `High` 等文字，不使用看多或看空風格。

## Design tokens

### 淺色主題

| Token | 數值 | 用途 |
|---|---:|---|
| `--bg` | `#F4F7FB` | 頁面背景 |
| `--paper` | `#FFFFFF` | 主要表面 |
| `--paper-soft` | `#F8FAFC` | 內層卡片及表頭 |
| `--ink` | `#14213D` | 主要文字 |
| `--muted` | `#526176` | 次要文字，須維持 WCAG AA 對比 |
| `--line` | `#DBE3EF` | 邊框及分隔線 |
| `--blue` | `#1E40AF` | 事實、導覽及主要資料 |
| `--blue-2` | `#2563EB` | 啟用與互動狀態 |
| `--blue-soft` | `#E8EFFF` | 藍色調表面 |
| `--amber` | `#B45309` | 估計及不確定性 |
| `--amber-soft` | `#FFF7E6` | 估計提示 |
| `--red` | `#B42318` | 重大下行機制 |
| `--red-soft` | `#FFF0EE` | 風險提示 |

### 深色主題

使用接近海軍藍的表面，不使用純黑。主要文字接近白色，次要文字仍須易讀，邊框也要清晰可見。隨附模板包含 canonical 深色數值。

### 字體

- 使用系統無襯線字體，加入 `Noto Sans TC`、`PingFang TC` 及 `Microsoft JhengHei` 作為離線繁中 fallback。
- 股票代號、日期、單位、識別碼、圖表數值與章節 kicker 使用系統等寬字體。
- 不強制依賴 web font。外部字體雖可增加一致性，但違反預設離線契約。
- 內文行高為 `1.65–1.75`。
- 手機內文至少 `15px`；桌機長文在空間允許時使用 `16px`。
- 財務表格與 KPI 數字使用 tabular numerals。

### 幾何規則

| 元素 | 標準 |
|---|---|
| 內容寬度 | 最大 `1180px` |
| 主要章節圓角 | 桌機 `18px`、手機 `16px` |
| 內層卡片圓角 | `12–14px` |
| 章節間距 | `24px` |
| 互動轉場 | `150–250ms`，只改顏色、邊框或透明度 |
| 陰影 | 柔和海軍藍陰影；列印時移除 |

## 元件契約

### 浮動工具列

顯示股票代號、報告名稱、資料截止日及精簡操作。支援切換主題與列印／輸出 PDF。工具列採 sticky 定位，與螢幕邊緣保留距離，不得遮住錨點標題。

### 章節導覽

桌機使用 sticky 左側導覽；手機使用可橫向捲動的短章節名稱。可用 `IntersectionObserver` 標示目前章節，但沒有 JavaScript 時仍須能正常導覽。

### Hero

包含公司身分、股票代號、報告名稱、一句因果摘要、研究階段、信心、資料截止日及幣別。避免股票圖片、裝飾性照片、目標價及宣傳性主張。

### KPI 卡

每個 KPI 都要有期間、單位、分類及簡短解讀。不得呈現沒有標籤的數字。首屏最多只放二至三項定義目前研究狀態的指標。

### 證據提示

Callout 必須說明結論邊界、重大不確定性或數字的分析意義，不可只用來做一般強調。

### 情境卡及表格

情境必須改變營運機制，不能只改估值倍數。顯示情境名稱、預測期間、主要營運假設、點估或區間，以及成立所需證據。說明各情境是獨立年度邊界或累積財測。

### 圖表

小型離線圖表優先使用無障礙 CSS 或 inline SVG。包含可見標題、單位、期間、標籤及文字解讀。顏色不能是唯一編碼。避免 3D 圖、儀表板量表、裝飾性漸層及沒有標籤的座標軸。

### 時間軸

用於認列順序、里程碑或證據變化。每個項目都包含 ISO 日期或財務期間、事件及分析影響。

### 風險列

每項風險都要說明以下機制：

`風險事件 → 營運指標 → 營收或利潤率 → EPS → 現金流或資產負債表後果`

裝飾性嚴重度量表是選配；若使用，也必須附文字標籤，不得暗示沒有根據的精確度。

### 資料來源

列出來源名稱、發布者、發布或申報日期、查閱日期、URL，以及長篇文件的頁次或章節。區分第一手及第二手來源。來源連結可能需要網路，但報告版面不需要。

## 響應式行為

| 寬度 | 預期行為 |
|---:|---|
| `1440px` | 完整雙欄、sticky 導覽及寬幅比較 grid |
| `1024px` | 空間允許時維持雙欄；表格在自身容器內捲動 |
| `768px` | 主內容改為單欄；KPI grid 可維持雙欄 |
| `375px` | 卡片及情境全部單欄、標籤換行、頁面不橫向捲動 |

長識別碼、URL 及標題必須換行。資料表格使用局部橫向捲動容器，不得撐寬整個頁面。

## 無障礙

- 內文及重要控制項符合 WCAG AA 對比。
- 使用語意化 landmark、標題順序、表格、按鈕及連結。
- 提供清楚可見的 `:focus-visible` 狀態。
- 純圖示控制項必須有無障礙標籤與 title。
- 使用同一套圖示家族的 inline SVG，不用 emoji 當介面圖示。
- 顏色不能是唯一的證據或風險指標。
- 尊重 `prefers-reduced-motion`。
- 必要圖片提供有意義的 alt；裝飾性圖片使用空白 alt。

## 列印與離線契約

- CSS、圖示及 JavaScript 內嵌於 HTML。
- 不依賴遠端 stylesheet、字體、圖片或圖表函式庫。
- 列印時隱藏導覽及操作控制項。
- 列印時移除陰影及半透明效果。
- 在支援的瀏覽器中使用 `print-color-adjust` 保留有意義的背景色。
- 在可行情況下，避免小卡、callout、情境區塊或表格列被拆到不同頁。
- 列印後即使沒有展開 URL，連結文字仍須可讀。

## 內容完整性

- 報告明確標示資料截止日。
- 事實、估計、假設、意見及管理目標可以區分。
- 幣別、單位、財務期間及已申報或調整後狀態清楚可見。
- 營收在轉換成 EPS 前，要橋接毛利、營業費用、融資、稅、持分及稀釋股數。
- 分開經常性、循環性、專案型及非經常性獲利。
- 區分認列延後與永久經濟損失。
- 一至兩項主要 EPS 風險具備可觀察預警訊號。
- 投資論點的確認與否證條件明確。
- 正常化獲利或可歸屬經濟尚未建立時，估值應暫緩。

## 實作

使用 [`../../templates/reports/investment-research-report.html`](../../templates/reports/investment-research-report.html) 作為 canonical 實作起點。將它複製到指定輸出位置，再取代通用展示內容。不要把最新公司事實寫入模板。

模板使用語意化 HTML、CSS custom properties、inline SVG、主題切換、列印支援、響應式版面及選配的目前章節導覽，而且完全沒有外部依賴。
