# 估價政策

<!-- 衍生繁體中文閱讀版；英文原檔 `Valuation.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

估值遵循業務和獲利分析。它估計顯式操作場景的影響；它不決定業務質量，也不是建議。

## 依經濟學選擇方法

|方法|適當的時候 |主要限制 |
|---|---|---|
|本益比|獲利為正、具代表性且歸屬於普通股股東 |因槓桿、一次性、週期性與會計政策而扭曲 |
| EV/EBITDA | 資本結構不同，或折舊／攤銷影響比較 | 忽略資本支出、營運資金、稅與稀釋 |
| P/B 或剩餘收入 |受監管的金融或資產驅動的回報與帳面權益掛鉤|帳面價值未必代表經濟資產價值|
|折現現金流量|長期現金產生和再投資可以明確建模|對終值和折現率高度敏感|
|部分總和 |各個細分市場具有不同的經濟狀況、同業或所有權結構 |企業集團成本、稅收洩漏和變現折扣很重要|
|資產淨值 |可辨識資產或項目具有可估計淨值和時間安排|對評估、竣工成本、稅收和折扣時間敏感 |

當業務支援時，至少使用一種主要方法和第二種方法作為合理性檢查。

## 首先標準化

在應用倍數之前，將報告收益與可持續收益進行核對。根據重大資產銷售、投資收益、公允價值變動、重組、經濟合理時的購電協議攤銷、異常稅收以及高峰或低谷週期條件進行調整。顯示每一次調整； 「調整後每股盈餘」並不是不言自明的。

## 場景結構

每個估值都應與下行、基本和上行操作案例相關。在評估假設之前，情境必須改變營運假設。

| 要素 | 下行 | 基準 | 上行 |
|---|---|---|---|
| 營收驅動因素 | 明確的不利機制 | 證據支持度最高的因果路徑 | 明確的有利機制 |
| 利潤率 | 稼動率、組合、定價或成本的結果 | 可持續的中間估計 | 有證據支持的營運槓桿 |
| EPS品質|定期和一次性分割|定期和一次性分割 |定期和一次性分割 |
|倍數或折扣率 |反映品質與風險 |符合經濟學|需要改進證據 |

## 多項選擇

將倍數錨定於永續成長、增量資本回報、週期性、資產負債表風險、治理和證據品質。歷史樂團和同行是背景，而不是權威。在比較公司之前解釋結構差異。

對於遠期本益比，請指定：

- 預測期；
- 報告或標準化稀釋每股收益；
- 淨現金、投資和少數群體的處理；
- 為什麼所選倍數適合成長和風險；
- 對最不確定的 EPS 驅動因素的敏感度。

## DCF 紀律

- 透過營運驅動因素預測收入。
- 將營業利潤與無槓桿自由現金流進行調整。
- 明確模型再投資和營運資金。
- 使用與經濟和行業限制一致的最終成長率。
- 將折現率敏感度與經營敏感度分開。
- 報告終期價值的比例；高度依賴會降低信心。

## 資產及專案業務對於建設和開發，按歸屬所有權、預期完工、收入確認、利潤、稅收、現金回收和機率對項目進行建模。對遙遠的項目進行折扣，不要重複計算土地或積壓訂單。

## 所需揭露

每份估值記錄都必須說明截至日期、價格來源（如果使用市場比較）、貨幣、股票數量、淨債務或現金、標準化收益橋、選擇的方法、情境假設、敏感度和限制。
