# 研究清單

<!-- 衍生繁體中文閱讀版；英文原檔 `ResearchChecklist.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

使用此清單作為品質門。當記錄為具有具體解決方法的開放式問題時，「未知」是可以接受的。

## 背景和範圍

- [ ] 所需的儲存庫上下文已依規定順序讀取。
- [ ] 公司身分、市場、股票代號、會計年度及報告貨幣明確。
- [ ] 研究問題和時間範圍明確。
- [ ] 審查了相關行業和模型指南。

## 企業品質及優勢

- [ ] 產品、客戶群、收入模式和細分市場經濟已映射。
- [ ] 解釋顧客價值和購買標準。
- [ ] 提出的競爭優勢有證據、機制和侵蝕風險。
- [ ] 了解資本強度、現金轉換與再投資需求。

## 營收和每股盈餘

- [ ] 收入變化分解為數量、價格、組合、份額、收購、週期和外匯（如果相關）。
- [ ] 毛利率和營業利益率的變動有因果解釋。
- [ ] 庫存、利用率、購電協議攤銷、投資收入、稅收和稀釋在重要的地方得到解決。
- [ ] 報告每股收益與標準化每股收益一致。
- [ ] 經常性收益、週期性收益、基於專案的收益和非經常性收益是分開的。

## 未來可見度

- [ ] 評估待辦事項或遠期指標的品質和時間安排。
- [ ] 預測涵蓋至少三年和更廣泛的兩到五年。
- [ ] 每個主要的當前驅動程式都有一個指定的替換驅動程式或一個明確的差距。
- [ ] 基本情況、上行情況和下行情況會改變營運假設。
- [ ] EPS 最敏感的不確定性是可辨識的。

## 論文和風險

- [ ] 論文闡述了可持續獲利機制。
- [ ] 一種或兩種 EPS 相關風險量化或有界。
- [ ] 確認和證偽訊號是可觀察的且有時限的。
- [ ] 支持和反駁證據都已呈現。
- [ ] 信賴度與證據成熟度一致。

## 估值

- [ ] 估值遵循業務和獲利評估。
- [ ] 主要方法符合經濟學。
- [ ] 一次性收益和高峰週期收益沒有合理理由不資本化。
- [ ] 經營假設與多重或折現率假設分開。
- [ ] 揭露幣種、期間、股數、淨債務和敏感度。

## 證據和歷史

- [ ] 重要事實引用了可用的主要來源。
- [ ] 事實、管理主張、估計、假設和意見是可區分的。
- [ ] 歷史假設和問題狀態仍然保留。
- [ ] 每個已解決或被拒絕的問題都包含證據和論文影響。
- [ ] 註明日期的變更使用 ISO 格式。

## 儲存庫完整性

- [ ] 所有受影響的規範文件一起更新。
- [ ] `meta.yaml` 反映目前狀態、下一步操作和觀看項目。
- [ ] 可重複使用的見解提升為產業、模型或研究日誌。
- [ ] 相關連結和標題有效。
- [ ] `python3 scripts/validate_repository.py` 通過。
