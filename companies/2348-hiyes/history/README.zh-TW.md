# 季度研究歷史

<!-- 衍生繁體中文閱讀版；英文原檔 `README.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

目錄保存 Hiyes 研究狀態的時間點季度快照。快照可以讓未來的分析師重建已知的、假設的和未解決的問題，而無需重寫編號的當前狀態檔案。

將快照命名為 `YYYYQn.md`。每個快照應說明快照日期、資訊截止、論文、報告和標準化收益觀點、關鍵假設、懸而未決的問題、信心和下一步行動。一旦提交，快照就只能追加；更正屬於稍後的快照或註明日期的更正部分。

2026 Q2財報發布後的檢視另存於[`2026Q2-filing-review.md`](2026Q2-filing-review.md)，因為[`2026Q2.md`](2026Q2.md)保留財報發布前的時點狀態。
