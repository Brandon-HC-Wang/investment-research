# Quarterly Research History

This directory preserves point-in-time quarterly snapshots of the Hiyes research state. Snapshots let future analysts reconstruct what was known, assumed, and unresolved without rewriting the numbered current-state files.

Name snapshots `YYYYQn.md`. Each snapshot should state the snapshot date, information cutoff, thesis, reported and normalized earnings view, key assumptions, open questions, confidence, and next action. Once committed, a snapshot is append-only; corrections belong in a later snapshot or a dated correction section.

The post-filing review for 2026 Q2 is preserved separately in [`2026Q2-filing-review.md`](2026Q2-filing-review.md) because [`2026Q2.md`](2026Q2.md) records the pre-filing point-in-time state.
