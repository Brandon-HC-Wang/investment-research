# Earnings Sources

Store annual reports, quarterly financial reports, earnings releases, and structured extractions here. Filenames should begin with the reporting period, such as `2026Q2-`, and identify the issuer or regulator.

For every artifact, retain publication date, access date, source URL, reporting currency, fiscal period, and page references. Earnings conclusions belong in `../../02_financials.md` and forecast changes in `../../04_eps_model.md`.
