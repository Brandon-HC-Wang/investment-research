# Source Library

This directory stores local source artifacts or source-specific notes for Hiyes when retention is lawful and useful. No existing research has been moved here. Canonical conclusions remain in the numbered company files and must cite their source path or URL.

## Categories

- [`earnings/`](earnings/README.md): audited reports, interim reports, earnings releases, and extracted filing tables.
- [`conference_calls/`](conference_calls/README.md): call transcripts, presentation materials, and analyst notes tied to a specific event.
- [`monthly_revenue/`](monthly_revenue/README.md): exchange disclosures and reconciliations of monthly revenue to segments or projects.
- [`news/`](news/README.md): external reporting retained only when it adds decision-relevant evidence unavailable in primary sources.

Use ISO dates in filenames, followed by a short source label. Preserve original documents; put interpretation in the numbered company records or a clearly labeled companion note.
