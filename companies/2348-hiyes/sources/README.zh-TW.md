# 來源庫

<!-- 衍生繁體中文閱讀版；英文原檔 `README.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

當保留合法且有用時，此目錄會儲存 Hiyes 的本機來源工件或來源特定註解。沒有現有的研究被轉移到這裡。規範的結論保留在編號的公司文件中，並且必須引用其來源路徑或 URL。

## 類別

- [`earnings/`](earnings/README.md)：審計報告、中期報告、收益發布和提取的歸檔表。
- [`conference_calls/`](conference_calls/README.md)：與特定事件相關的通話記錄、簡報資料和分析師註釋。
- [`monthly_revenue/`](monthly_revenue/README.md)：交換各部門或專案的每月收入揭露與調節。
- [`news/`](news/README.md)：僅當外部報告添加了主要來源中不存在的決策相關證據時才保留。

在檔案名稱中使用 ISO 日期，後面跟著簡短的來源標籤。儲存原始文件；將解釋放入編號的公司記錄或明確標記的隨附註釋中。
