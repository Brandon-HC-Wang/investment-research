# 公司研究記錄

<!-- 衍生繁體中文閱讀版；英文原檔 `README.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

每個子目錄都是一家上市公司的規範累積記錄。目錄使用小寫 ASCII 形式的 `<ticker>-<slug>`；一級上市市場屬於`meta.yaml`。不要在此處建立演示或占位公司。

## 永久檔案合約

每個公司目錄必須包含：

|文件 |規範責任|
|---|---|
| `01_business.md` |產品、客戶、收入模式、產業地位與競爭優勢 |
| `02_financials.md` |歷史績效、獲利品質、現金流量、資產負債表與資本配置|
| `03_growth_drivers.md` |收入驅動因素、積壓或領先指標、替代驅動因素與風險 |
| `04_eps_model.md` |因果預測、情景、假設和報告至標準化 EPS 橋 |
| `05_timeline.md` |僅附加日期里程碑和論文/模型變更 |
| `06_notes.md` |來源觀測尚未完全整合到其他地方|
| `07_open_questions.md` |具有 `Open`、`Resolved` 或 `Rejected` 狀態的持久問題登錄 |
| `08_thesis.md` |當前論文、變體觀點、風險、證偽測試和記分卡 |
| `09_valuation.md` |方法選擇、標準化估值、情境與敏感度 |
| `meta.yaml` |穩定的機器可讀公司身分和遺留工作流程欄位 |

## 補充研究狀態

每家公司還包含：

|路徑|責任|
|---|---|
| `assumptions.md` |使用 `Open`、`Verified` 和 `Rejected` 的僅附加假設 |
| `research.yaml` |涵蓋工作流程、審核時間、置信度和監控狀態 |
| `history/` |名為 `YYYYQn.md` 的不可變季度研究快照 |
| `sources/` |按收益、電話會議、每月收入和新聞組織的來源工件 |

這些添加是向後相容的。編號的公司文件和 `meta.yaml` 仍然存在並保留其現有責任。

複製 [`../templates/company/`](../templates/company/) 開始一家真正的公司。以來源研究取代所有教學內容；範本說明不得保留在活動的公司資料夾中。

當本地保留合法且必要時，支援材料可儲存在 `sources/` 中。與複製的文檔相比，更喜歡連結和源元資料。
