# 聯詠 — 估值

截至 2026-11-05；TWD/share。先完成業務與可持續獲利分析，再閱讀本紀錄。主要方法：正常化 P/E；合理性檢查：可用現金與 FCF。因再投資及客戶平台能見度不足，暫不建立 DCF。

## 觀察參考

**事實：** TWSE 日資料 API 最後回傳 2026-11-04 收盤 TWD533，不是 2026-11-05 收盤或即時價。九月底發行股數 611.512m，對應市值約 TWD325.9bn；模型稀釋股數 612m 是另一項前瞻假設。[S2 pp. 6, 34；S7]

**計算：** 近四季報導基本 EPS = 9M2026 26.58 + Q4 2025 6.07 = 32.65，P/E = 16.32×。FY2025 基本 EPS 26.87 對應 19.84×。近四季含投資利益；基本與稀釋 EPS 不互換。FY2026 條件 EPS 31.8–37.6 對應約 14.2–16.8×，FY2027 中央敏感度 33.5 對應約 15.9×。這些比率是輸出，不是投資結論。[S2/S5；模型 JSON]

## 觀察價格需要多少獲利？

這些**不是選定合理倍數、歷史區間或目標價**，而是顯示估值需要哪些可持續獲利。FY2027 中央敏感度不足以支持 12× 所需 TWD44.4 EPS；上行需要實際組合／量產證據。合理倍數仍需當前同業／循環比較及增量研發回報，尚待解決。

## 資產負債與現金流檢查

現金 TWD40.556bn，按發行股數為每股 TWD66.3，尚未扣租賃、存入保證金義務、營運需求與未來資本承諾。公允價值證券不是現金，OCI 利益不是經常獲利。不能一面保留利息收入、一面把全部現金加在 P/E 價值上，也不能把全部負債都當金融借款。[S2 pp. 5–6, 16, 35]

9M FCF 代理值 TWD11.598bn／示意市值 TWD325.9bn 約 3.6%，是**九個月**，並非年度前瞻殖利率。時點、存貨及資本承諾使直接年化不可靠。已支付 TWD23 現金股利／533 = 4.3%，只屬歷史價格比較，不是未來配息預測。[S2 pp. 9, 24]

結論：獲利品質與存貨解決進度，比表面倍數更重要。不採用目標價或交易指示。下次證據關卡 2026-11-06；[未解問題](07_open_questions.md)、[來源](sources/README.md)。
