## 驗證儲存庫

從儲存庫根運行：

```bash
python3 scripts/validate_repository.py
```

驗證器僅使用Python標準庫。它檢查所需的頂級文件和目錄、固定公司文件名、非空降價、元資料欄位和受控值、ISO 日期以及活動公司記錄中常見的未解析模板標記。

退出代碼 `0` 表示驗證已通過。退出代碼 `1` 表示列印了一項或多項合約違規行為。驗證器有意保守：它檢查結構完整性，而不是投資分析的正確性或來源品質。
