# 未來自動化的想法

<!-- 衍生繁體中文閱讀版；英文原檔 `README.md` 是唯一 canonical source。若內容衝突，以英文版為準。 -->

該目錄是設計待辦事項，而不是可執行的自動化。這裡沒有實現任何腳本。

## `update_monthly_revenue.py`

潛在目的：取得官方每月揭露資訊、保留原始來源、規範期間和單位、比較修訂版本並準備可審查的公司更新。它絕不能自動推斷論文影響或涵蓋公司研究。

## `update_watchlist.py`

潛在目的：從經過驗證的 `research.yaml` 檔案建立派生的監視清單視圖。 `research.yaml` 仍然是規範的；生成的視圖必須可重複且清晰標記。

## `check_open_questions.py`

潛在目的：索引公司和行業問題，驗證允許的狀態，標記過時的審核觸發器，並保留已解決或拒絕的歷史記錄。

## `earnings_calendar.py`

潛在目的：從官方交易所或公司來源收集即將發布的報告日期，記錄來源並標記不確定性。它不得創建獲利預測或交易訊號。

## 實作門

在任何想法成為程式碼之前，定義輸入來源、模式、故障行為、冪等性、稽核追蹤、測試、手動審查邊界以及是否需要網路或憑證。自動化可能會提出更改；它不能默默地修改僅附加歷史記錄。
